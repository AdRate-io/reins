## 起因与做法

AdRate 要在主进程上线 reins（createAgent + handler，前后台共用 runs 登记表与租约）。上线前对 12 个包做一次全库审查：实现与设计 bug、漏网问题、公开与维护者文档错误。

- **审查**：多路子代理按包与维度扇出，每条发现再经独立核实，汇成 111 项（high / medium / low），按"上线前必修 → 安全与信任边界 → 其它行为错误 → 文档"四批排期。
- **修复**：第一波按项并行；Boss 调整节奏后，第二、三波改为一个子代理修 3～5 个相关问题、每批一次独立审查与返修（G1～G7、D1 / D2）。变异验证须按进程组超时收尸（一次孤儿 vitest worker 吃满内存的事故后写进 AGENTS.md 工作方法）。
- **需拍板项**：#54（beforeModel 补丁工具在续跑补跑时不在场）记 OPT-261125-5，Boss 选第 3 案（不改契约，要审批 / 客户端执行的工具只走静态贡献，补跑时如实落"续跑时不可用"）。
- **发版前终审**：三路独立终审只看单批审查看不到的交互，拦下一个阻断项——两批修复叠加后，同批已有审批中断时再遇宿主中止，暂停不带 note，没走过判定的客户端工具可免审批回填（9856645）；另修 brain 自带工具认副本、TanStack 的 needsApproval 抛错与 Socket 客户端工具取消等，余项登记 OPT-261125-10～13。
- **真模型冒烟**：AdRate 只读巡检，DeepSeek v4-flash 与 Sonnet 5.5（CF 网关）均 done、结论一致，约 $0.45。
- **结果**：108 项已修、3 项转 OPT / BUG（#18 → OPT-261106-4、#80 → BUG-261125-2，#54 已定案）；发 v0.23.0（core 0.18.0 / agent 0.8.0），全量 2561 用例（含真库列）与 CI（PG 16.13）通过。
