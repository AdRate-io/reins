## 1. 定位一句话

可嵌入的 Agent 库：装上、配自己的模型，得到一辆有驾驭经验的车。两条宪法——决策权默认在模型；时间线是唯一真源、角色只是翻译。不是框架、不是运行时、不是应用、不是平台（PRD §3）。

## 3. 数据模型：一条时间线

只有一种数据——带发起者的事件 `Event { id, sessionId, seq, type, schemaVersion, actor, payload, provenance?, trust?, meta? }`。EventLog **只 append**，seq 由调用方分配、日志校验同会话连续（首条 1），不连续抛 `seq_conflict`，这就是乐观并发。读时按注册表 upcast，查不到升级函数即拒绝。

当前 16 种核心事件（`packages/core/src/events/core.ts`）：

| 类别 | 事件 | 模型可见 | 谁写 |
| --- | --- | --- | --- |
| 对话 | `user_message` `model_thinking` `model_text` `tool_call` `tool_result` | 是 | 宿主 / 降级层 / 循环 |
| 说明 | `system_note`（kind = host / pin / …，`supersedes` 取代旧条，`directive` 标要模型去做的指令） | 是 | 宿主 / pins / handoff / compact |
| 整理 | `compaction`（模型自决或阈值兜底；摘要后附被折叠工具结果清单） | 是 | compact / 投影兜底 |
| 运维 | `approval_request` `approval_decision` `run_paused` `run_resumed` `budget_usage` `memory_op` `handoff` `error` `tools_bound`（每次 run 起步一条工具表快照，P1） | **否**（投影过滤） | 循环 / 模块 |

`tool_result` 可带 `spilled.blobId`（外溢），`system_note` 可带 `meta.pin`。内容段 `ContentPart` 三种：text、image、`tool_reference`（工具定义引用，带 name / description / inputSchema 快照——`tool_find` 结果用它，L1；降级层有原生能力发引用块由厂商展开，否则 `renderToolReference` 展开成文本）。宿主自定义事件 `ext.*` 走自己的注册表。

## 4. 循环与插座（§7）

`runLoop(config)` 是导出的普通异步生成器：yield 每条刚 append 的事件，返回 `RunResult` 四态 `done | paused | handoff | error`。暂停是返回值不是回调，`paused` 带可序列化、HMAC 签名的 `SerializedRunState`（含 `configHash`，续跑校验，漂移 fail-closed，`allowConfigDrift` 可显式放行）。 `Interruption` 五种：approval / client_tool / budget / host / **subagent**（子代理即工具的暂停冒泡，§10.1，2026-09-10）。

一次 run 的骨架：

```
起步：解析静态贡献（Socket.tools / systemPrompt，可异步，整 run 不变）→ configHash → 校验 resume / decisions（一条日志不写直到全过）
      → append tools_bound 快照（与上一条比对有增删则再 append 模型可见的工具变化说明，P1）→ 落新输入
每轮：beforeModel(补丁) → 投影 → 降级 → 模型（瞬断有限重试）→ afterModel
      → 对每个 tool_call：beforeTool 链（block / defer / rewrite）→ 未知工具 → validate → 审批判定 → 客户端工具转暂停 → execute → afterTool 链
      → endTurn：onTurnEnd 第一个给意见的定（continue / stop / pause / handoff），无意见则"有工具调用就继续"
续跑：补齐 pending 的 tool_call 后也走一次 endTurn（被打断的那一轮到此才算结束）
```

Socket 契约（`packages/core/src/loop/types.ts`）：静态贡献 `tools` / `systemPrompt`（常量或按 `SocketSetup` 算一次的函数，可异步——MCP 在此 `tools/list`；返回 undefined 即不贡献）；钩子 `beforeModel` `afterModel` `beforeTool` `afterTool` `onTurnEnd`。多个 Socket 按注册顺序执行。

投影（§8）：过滤（运维事件不给模型；trust 标注由降级层包裹）→ 折叠（compaction 之前的原件收起，pin 幸存）→ 阈值裁剪兜底（按"估算 + 上一请求校准出的固定开销"比裁剪目标，与感知读数同一函数）。投影是纯函数，回放用同一份。

## 6. 存储（§5）

`Stores = { log: EventLog, blobs?: BlobStore, memory?: MemoryStore, runLease?: RunLease }`，只有 log 必需。内存实现在 core（`memoryStore()`，不带 runLease）；SQLite 与 Postgres 实现各一个包，四份一致性测试套件在 `@reinsjs/core/testing`，两个实现共跑。表：`reins_events` / `reins_blobs` / `reins_memory`，pg 另有 `reins_runs`（D4 run 租约，过期用库时钟）；只有记忆表名可配（`memoryTable`，多角色各一张记忆表、共用日志），事件表与 blob 表按 `session_id` 隔离不可配。

| 表 | 说明 | 保留策略 |
| --- | --- | --- |
| `reins_events` | 事件时间线，主键 `(session_id, seq)` 即并发闸；整条存 `data`（pg 是 **json** 不是 jsonb），壳字段抽列 | **不可删**（只 append，压缩 / 外溢 / 交接都以追加事件表达） |
| `reins_blobs` | 外溢的大工具结果，按 session 隔离；`fetch_blob` 按"本会话时间线引用过"授权 | 库不删，生命周期归宿主 |
| `reins_memory`（表名可配 `memoryTable`） | 模型的记忆文件（KV，目录隐含），键 = namespace 前缀 + 规范路径 | 模型经 `memory` 工具增删改，`memory_op` 留痕 |
| `reins_runs`（仅 pg） | 跨实例 run 租约（D4），三条单语句，过期只比库时钟 `now()` | 硬删（结束即 release） |

记忆隔离三层（§9.6）：存储实例（哪张表）→ `memory({ namespace })` 前缀（同表内逻辑分区，按角色 / 用户）→ 路径（模型自决）。

## 7. 服务端与前端（§12）

`createAgentHandler(definition, options)`：POST 起 run 或续跑（`input` / `resume` / `decisions`），GET 从 `lastSeq` 补发；SSE 编码缺省 AG-UI（`@reinsjs/ui-agui`），可换原始事件。鉴权两层：`principal(request)` 解析"谁在问"，`authorizeSession({ sessionId, principal, method, isNew })` 决定"能碰哪条会话"，只有显式 `true` 放行，拒绝回 404。`sessionId` 必须是可打印 ASCII 无空格（`/^[\x21-\x7e]+$/`），否则 400。旁路观测 `onEvent(event, { sessionId, principal, request })`：经 handler 起的 run 每 append 一条事件调一次（只 live 不 replay），不挡 run、出错只告警；进程内 `agent.run()` 本身就是逐条 yield 的生成器，不需要它。同会话同时只允许一个 run（409 `run_in_progress`）：缺省 `InMemoryRunRegistry` 只认本进程；多实例部署用 `leasedRunRegistry(store.runLease)`（D4，`createAgent` 见 `store.runLease` 自动装）——起跑占租约、每 ttl/3 心跳、丢租约则本 run paused(host)、结束释放；跨实例 GET 只补发不接实时流。

另一条路径：`@reinsjs/adapter-tanstack-ai` 让 TanStack AI 的循环跑、reins 的日志记、脑子的钩子在 TanStack 的 middleware 钩子里执行。

## 10. 核心设计决策

> 回答"为什么系统长这样"。每条 = 决策 + 为什么 + 边界，一段话讲透。2026-10-30 从 0.1～0.4 的决策日志（`archive/2026-10-30-决策日志DECISIONS-0.1至0.4.md`，172 行，冻结）提炼；此后新决策落定当天写在这里，重大的链接 `implementation-plans/`。决策由技术合伙人做出，Boss 可随时否决。

### 定位与边界

- **两条宪法 + 整车形态**（2026-09-08，Boss 确认）— 决策权默认在模型；时间线是唯一真源、角色只是翻译。形态是"整车"：自带几百行可复制的 `runLoop` + 预装脑子 + 标准插座，脑子能脱离底盘装到别人的循环上（TanStack 适配器）。为什么：调研证明底盘已饱和、空白是可拆的驾驭经验层，且没有库把"决策权在模型"当立场。边界：不做框架、运行时、应用、平台（PRD §3）；多智能体只做子代理即工具与 handoff，不做编排器。
- **"等真需求"是加功能的门槛** — 0.1 之后的每个新能力都来自宿主的真实样本：AdRate（投放工具，dogfood 宿主）的接入评估催生 D1～D5、TikTok MCP 催生 MCP 进 lazy 菜单，OnSet（8 角色长期会话系统）催生 Chat 线图片上浮与口径对齐。没有样本的（memory 挂载表、工具并发、MCP sampling 等）一律搁置并写重启条件（`待处理任务.md`）。
- **缺省开关由 eval 跑数定，不拍脑袋**（2026-09-09～10，P8）— 模型自决类机制无 eval 达标不默认开。现状：compact（含清单 + recall）、perception、pins、spill（16k）、budget、approval 推荐默认；memory、handoff 不默认；skills、lazy-tools opt-in。改任何缺省先跑 `examples/eval`（DeepSeek 与 Claude 两族）。
- **公开与账户**（2026-09-14，Boss 定）— MIT、版权 NewRate Limited、GitHub `AdRate-io/reins`、npm 组织 `reinsjs`；npm 拒绝裸名 `reins`（与 `redis` 过近）后总包定为 `@reinsjs/agent`。docs/ 随仓库公开，代价是一条公开性规则（`docs/README.md` §4）；真实业务值全历史 filter-repo 换成别名。

### 时间线与循环（core）

- **事件只 append、seq 由调用方分配、日志只校验连续**（T3～T5）— seq 冲突即乐观并发失败（`seq_conflict`），不需要锁；fork 保留原事件 id 与 seq（id 唯一性范围是会话内），所以 pin 引用、被折叠清单、`recall({ seq })` 在分叉会话里继续有效。载荷统一在 `payload`、壳只校验版本，读时 upcast 只在 core `readTimeline` 一处做，查不到升级函数即拒绝。
- **暂停是返回值，续跑只有一条路**（T9 / T10）— 每轮先补齐时间线里没有结果的 tool_call，审批、宿主中止、进程死亡、客户端工具回填全走它；恢复 = 同一 sessionId 再跑一次。状态带 HMAC 签名（宿主给 `secret`）+ `pendingDigest` + `configHash`，校验全过之前一条日志不写；配置漂移缺省拒绝（暂停时模型看到的工具集就是它做决定的依据），`allowConfigDrift` 显式放行。
- **Socket 是唯一扩展契约**（T9 / B2 / B6 / P1）— 钩子 `beforeModel` / `afterModel` / `beforeTool` / `afterTool` / `onTurnEnd` + 静态贡献 `tools` / `systemPrompt`。模块工具走静态贡献而不是 beforeModel 补丁：补齐 pending 时它们必须在场，且要进 configHash 才能察觉模块拆装。静态贡献可异步（MCP 在此 `tools/list`），各 Socket 依次 await；每个 Socket 看到"到它为止已并入的工具表"（`SocketSetup.tools`，2026-09-22，lazy-tools 收 MCP 工具靠它）。
- **投影是同步纯函数，阈值兜底只是兜底**（T6，2026-10-30 修口径）— 过滤运维事件 → 折叠（摘要放在被覆盖区间的原位）→ 阈值裁剪。兜底判据是"估算 + 校准出的固定开销 > contextLimit − reserveTokens"，与感知读数同一函数，因为告诉模型的阈值必须是框架真会兑现的阈值（踩坑 40）。触发线与回落线分开（OPT-261030-2，2026-10-30）：过触发线才裁，一裁裁到 `contextLimit × cutToRatio`（缺省 0.6，高于触发线时按触发线）——只裁回触发线下会贴线磨刀，几乎每轮裁一截、每次缓存前缀整段作废、旧摘要再套一层；感知报的 `autoFoldAt` 仍是触发线。
- **prompt cache 共识**（2026-09-08，Boss 提出）— 动态信息（余量、预算档）只作为 `system_note` 追加在时间线末尾；系统提示与工具表每轮稳定；旧说明不删不藏；只有 compaction 允许打掉缓存且由模型在轮边界自决。实测 cacheRead 占比是 B1 的验收项。
- **瞬断重试只在零输出时**（2026-09-10 / R3）— 落了半截再断不重试（日志里不能有两份半截）；判定状态码优先（408/409/429/5xx，与两家 SDK 同策略），文案关键词只在没有状态码时兜底；判不出当非瞬断。
- **用户插话不改日志顺序**（2026-09-09 审查）— 用户什么时候说的就记在什么位置；"tool_result 必须紧跟 tool_use"由降级层后移并声明 `lossy(user)`。改循环让输入等 pending 只是把问题挪个地方。
- **工具批串行执行**（2026-09-21）— 事件按发生顺序 append 是宪法二的直接后果；并发搁置（OPT-260921-1）。
- **子代理即工具**（2026-09-10，Boss 提出）— 专家以 `Tool.execute → agent.run()` 挂在编排者工具表上，手写范式容易漏五件事（技术方案 §10.1）：① 中止传递、② 身份传递（`principal` 原样下传）、③ 时间线关联（子 sessionId 写进父 `tool_result`）、④ 预算合算、⑤ 审批冒泡。`asTool` 收掉其中做不对的：子会话 id 缺省 `${父 sessionId}:${toolCallId}`、子 paused 整体以 `Interruption(kind=subagent)` 冒泡且结论按 `decisions[].sessionId` 转发、子用量经 `ctx.spend` 只加 tokensSpent。**联停与否由使用者决定**（Boss 补充）：缺省传 signal 父停子停，接力式编排（财务做完交法务）可不传。

### 脑子模块（brain）

- **感知做 Socket、只陈述不下指令**（B1）— `beforeModel` 只 emit 一条 `system_note`，数值先分档再给模型，按渲染后的文字判重（宿主换 render 后模型看到的没变就不追加）；读数按上一请求真实用量加法校准（漏掉的是系统提示 / 工具表这类常量，比例校准会随历史放大误差）。2026-10-30 起缺省 render 不报会话累计 token 与未折叠轮数（对模型决策无用、跨档噪音大），读数仍保留。
- **compact：给"会消失"配"拿得回来"**（B2 / E3c）— 模型自决整理 + 阈值兜底；摘要后自动附被折叠工具结果清单，`recall({ seq })` 逐字取回。为什么不是"引导模型逐字保留"：两族实测文案改不了模型的取舍，宪法一也不许替它决定留什么。最近一条用户消息缺省幸存（模型复述不了还没处理的指令）。规则文案不点名 perception 标题（宿主可能换 render 或没装感知，2026-10-30）；缺省规则不加"run 收尾前整理"一句——onset-pause 66 格证明它无效（1/25 对 0/24）。 2026-10-31 起中间加一层"到线请模型整理"（OPT-261030-3 / OPT-261031-1）：过 75%、80% 各在末尾追加一条指令类说明（`directive`，降级层以带标签的 user 送达——号池中转站对中途 system 里的指令不执行）请它先 `compact`，照做记 `decidedBy: "forced"`，不理才到 85% 机械裁到 60%；缺省开，门禁 DeepSeek 官方照做 12/12、召回 35/36，强制 tool_choice 与收窄工具表因 400 / 缓存归零被否（`spikes/forced-compact/`）。
- **pins 用"取代"而不是 unpin**（B3）— append-only 下唯一的撤销表达是被后来者取代（`supersedes`）；模型只能替换自己钉的，宿主 pin 是宿主的约束。字数校验两成容差（踩坑 18）。
- **spill 存而不截**（B4 / B9 附）— 大结果缺省进 blob 并给 `fetch_blob`，`overflow: "truncate"` 才截且向模型明说不可恢复；授权按"本会话时间线引用过"，fork 会话能取、未引用的 id 当不存在。
- **approval 是 Socket、放 sockets 末尾、先 validate 再判定**（B7 / R1 / D3）— 放末尾让前面的 `rewrite` 绕不过按入参写的规则；校验不过的调用不问人；allow 不留事件（否则日志翻倍、信息量为零）。它不只是安全网：两族实测没装它时模型会"列完候选停下等批准"，装了就敢动。`ttlMs` 比循环时钟不读墙钟，过期以 deny + block 落地。
- **记忆隔离三层，不加"角色"字段**（2026-09-10）— 存储实例（表）→ `namespace` 前缀 → 路径（模型自决）。角色由"哪个 `createAgent`"决定，不进事件、不进存储；只有记忆表名可配。
- **skills 渐进式披露、结果 system 信任**（S1，2026-09-13）— 菜单进系统提示（run 内不变），`skill_read` 翻书，正文以 tool_result 进时间线；载体是 `MemoryStore` 的只读子集。缺省上限 40k 字符是硬上限，按 Agent Skills 规范定（两族都不按截断提示续读说明书）。模型可写的位置（`/memories`）不能当技能根，否则模型自己写出 system 信任的技能。
- **lazy-tools 两路**（D1 / L1）— 降级层有原生延迟加载（fetch 版 Anthropic 官方：`defer_loading` + `tool_reference`）就全表下发、取回不打掉缓存（实测取回后第 2 请求 cache_read Haiku 8497）；否则过滤路径，取回后首请求整段重写缓存、约 7 个请求回本，所以规则要求一次取全。已取回集合从时间线重建，不留内存状态。opt-in。

### 降级层

- **接口进 core、实现可换，两份并存、新宿主推荐 fetch 版**（T7 / F4，2026-09-15）— `Lowering` / `LoweredRequest.landings` / `LossMatrix` 在 core；pi 版复用 pi-ai（pin 0.85.1，类型不出包），fetch 版零依赖只用 `fetch`、三条线（Chat 含 DeepSeek 方言 / Anthropic Messages / Responses）、`payload.body` 即线上请求体。推荐 fetch 版的依据是数据：协议超集、矩阵更严、真模型三线全通、最严档 workerd 15/15。总包不带任何降级层。**书面豁免**（2026-09-10，至今未收口）：pi 版进阶导出 `draftsOf` / `consumeStream` / `eventsToContext` 等签名含 pi-ai 类型（d.ts 顶部 import pi-ai）；"pi-ai 类型不出包"的约束边界是**其它 `@reinsjs/*` 包不依赖 pi-ai 类型**，主路径（工厂、`PiLoweredPayload`）已 opaque。改成 `unknown` 或挪 `/internal` 是 breaking，见 `待处理任务.md` OPT-260910-3。
- **每条事件一个落点，有损必须声明**（宪法二推论）— exact / lossy / dropped，矩阵测试断言落点必在声明内、顺序与输入一致。协议装不下的内容先找"挪到哪能装下"（Chat 线工具图片上浮到同批之后的 user，2026-10-27），占位是最后一档。
- **回放不透明字段按 provider + api + model 精确匹配**（2026-09-15）— thinking 签名、Responses 加密推理项、`fc_` 项 id 都绑产出它的模型；不匹配一律 dropped 声明，不降成正文。
- **trust 标注在降级层、事件永远原文**（T6 / R9）— untrusted 内容包成 `<untrusted source="tool:<name>">…</untrusted>`，内容里的闭合标签转义并记 lossy；投影不篡改 payload。

### 服务端、存储与工程

- **server 是 Web 标准 handler，SSE 缺省推原始事件、AG-UI 是可插编码器**（T12 / T13）— seq 天然是 SSE id，重连补发零状态；总包 `createAgent` 缺省换成 AG-UI 编码（PRD：AG-UI 一等输出）。AG-UI 只翻译不发明，reins 特有事件一律 `CUSTOM`。发起者断开缺省 run 继续跑完。
- **鉴权两层、fail-closed、越权当不存在**（R6，2026-09-09）— `principal` 答谁在问，`authorizeSession` 在解析出 sessionId 之后、读写日志之前答能碰哪条会话，只认字面 `true`，拒绝回 404。客户端输入两道类型白名单（循环层 + server 层），审批结论只走签名保护的 `decisions`。
- **跨实例 run 互斥靠存储租约**（D4，2026-09-14）— `RunLease` 接口 + pg `reins_runs` 三条单语句（不用 advisory lock：会话级锁绑连接，池里解不了），心跳 ttl/3，丢租约本 run paused(host)。
- **存储：一份 SQL 多个驱动，单语句不开事务，pg 用 json 不用 jsonb**（S3 / B9）— node:sqlite / bun:sqlite / pg / PGlite 由宿主传入；jsonb 重排键序会让按 `JSON.stringify` 算的 digest 续跑误报篡改。
- **eval 是独立包、只依赖 core**（E1）— 臂就是 `LoopConfig` 片段，三臂同一个 `runLoop`；fixture 世界由录像长出来、写后可见；指标是时间线纯函数；门禁把 PRD 门槛 2 写成代码，跑数时不会临场放水。
- **运行时文案英文、注释与文档中文**（2026-09-15，JSDoc 保持中文由 Boss 拍板）— 宿主与模型会看到的一切（throw、warn、tool_result 说明、有损矩阵 note、占位文本、eval 报告）用英文。
- **发布纪律**（2026-09-14～15）— changesets 管版本，改公开行为必有 changeset，破坏性变更升 minor；发布只用 `pnpm -r publish`（`npm publish` 不重写 `workspace:*`，0.2.0 因此作废）；发前 `pnpm check:dist`，发后空目录从官方源真实安装冒烟。`REINS_VERSION` 单源手改，`check:dist` 核对。
