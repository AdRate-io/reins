## OPT-261105-3. 历史里的旧视频 / 音频每轮重发

- **记录日期**：2026-11-05（OnSet 建议 12 可选项）
- **背景**：媒体片段进了历史就每轮整段重发，一段视频 7k–20k token，一次 run 可能看好几段。OnSet 提议投影时把较早的媒体折成占位、只留最近 N 段。

- **优先级**：低。等 OPT-261105-2 发版、OnSet 跑出用量数据。

## BUG-261105-1. 内置模型表把 `deepseek-v4-pro` 写成收图，实际图片被静默丢掉

- **记录日期**：2026-11-05（`spikes/media-parts/` P 组）
- **现象**：官方 `GET /models` 写明 `deepseek-v4-pro` 的 `input_modalities` 只有 text。带图请求回 200，输入 token 只有 `deepseek-flash` 同一请求的一半（137 对 273），模型答"看不到"。

- **修复方向**：改成 `images: false`，让图落占位并记 lossy；changeset patch。并入视频 / 音频方案的实施清单一起做（同一个文件、同一组矩阵用例）。

## OPT-261102-2. TanStack 适配器的工具入参二次编码不解【维持不做】
