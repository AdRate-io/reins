# 到线请模型整理（OPT-261030-3）

> 状态：🚧 实施中

## 背景与根因

OnSet 反馈建议 4（`archive/2026-10-30-OnSet反馈-compact与perception改进建议.md`）。上下文到线后，现在只有机械裁剪一条路：摘要里只有类型计数、用户消息开头和工具结果清单，长会话最要紧的"目标、决定与原因、下一步"全丢。而靠文案劝模型主动整理已证明无效：onset-pause 两轮 66 格，规则补句与感知提示都改不动（1/25 对 0/24），模型在 28 万 token 上下文里根本不想上下文的事。

同日已落地的前置：
- OPT-261030-2：机械裁剪一次裁到回落线 60%，不再贴线磨刀（`4a57a7a`）。
- `spikes/forced-compact/`：两族上游实证，"前缀不动、末尾追加一句明确指令"两家都照做（DeepSeek 6/6、Haiku 5.5 3/3）且缓存命中 98% / 99.3%；强制 tool_choice 在 DeepSeek thinking 模式 400、在 Haiku 5.5 被接受但缓存归零；收窄工具表两家缓存都崩。

## 方案总览

三层，宪法一下的分工不变——模型决定写什么，框架只在模型没动时兜底：

1. **模型自决**（不变）：感知报用量，规则提示讲经验，模型自己挑停顿整理。
2. **请它整理**（新增）：用量过软线（缺省 75%）且本段（上次整理之后）还没请过，compact 的 `beforeModel` 在末尾追加一条说明，明确要求先 `compact` 再继续。模型照做产出的 compaction 记 `decidedBy: "forced"`。
3. **机械兜底**（不变，已改回落线）：过触发线（`contextLimit − reserveTokens`，缺省 85%）仍没整理，投影链机械裁到 60%。

**不动的部分**：投影链与触发线、感知读数与文案、compact 工具入参与折叠算法、recall、连续上限、各降级层、tool_choice（不加通道）、工具表（不收窄）。

## 具体设计

### core

- `CompactionPayload.decidedBy` 加 `"forced"`：时机是框架定的、内容是模型写的。注册表不校验载荷，旧日志照读；新增取值不升 schemaVersion（与 `SystemNotePayload` 加可选字段同一判断）。消费方里按 `=== "model"` 判的（`isModelCompaction`、eval 时机统计）语义是"模型自己挑的时机"，forced 不算进去，是对的；按 `=== "threshold"` 判的（`isPreModelEvent`）不受影响——forced 的 compaction 由工具产生，在日志里就在模型输出之后。

### brain / compact

- 新选项 `force?: false | { at?: number; render?: (info: { usage: string; autoFoldAt: string }) => string }`。`at` 取 (0, 1)，缺省 `DEFAULT_FORCE_AT = 0.75`；`render` 给宿主换语言，必须是纯函数。
- `beforeModel`：用量 = `(ctx.budget.used + contextOverheadOf(ctx.timeline)) / contextLimit`——与感知读数、阈值兜底同一把尺（真源 core `contextOverheadOf`）。过 `at`、且时间线里最后一次 compaction 之后没有请求说明，就 emit 一条 `system_note(kind: "budget", meta: { compactRequest: { usage, at } })`。无状态：判据全从时间线读，续跑与多 run 都成立。
- **每段只请一次**：模型不理，不再追问——留给 85% 的机械兜底。理由：反复追加说明会在模型正干活时一再打断；实证照做率高，先不为没观察到的情况加机制。eval 里统计"请了没理"的比例，出现再议。
- `afterTool`：本次 compact 调用之前、最后一次 compaction 之后有请求说明 → `decidedBy: "forced"`，否则 `"model"`。
- 说明文案（英文，模型可见）：`Context window is {usage} full; the harness folds the oldest turns mechanically at {autoFoldAt}. Before doing anything else, call \`compact\` now to fold the conversation so far into your own summary (use keepRecentTurns to keep the turns you are actively working from), then continue the task.`
- `COMPACT_RULES` 末条改为不带数字的三段说法：窗口接近满时框架会请你整理；仍不整理才机械折叠。
- `at` ≥ 触发线时这一层永远不出现（投影先裁了），README 写明，不另加告警。

### 缺省开关

依硬约束"模型自决类机制无 eval 不默认开"：先按缺省开实现；eval 门禁过了才保持缺省开，不过则缺省改 `force: false` 再发布。

**门禁**（全部满足才缺省开）：
1. 请到的格里先整理（第一个工具调用是 compact）≥ 80%；
2. 预埋事实召回不低于第二轮现行臂（允许差 1 格）；
3. early 对照切点（< 50%）不出现请求说明、不整理；
4. 带请求说明那次请求的缓存读占比不低于同格前一次请求减 5 个百分点。

**花费**：DeepSeek v4.1 flash 经公司中转站，按前两轮每格上限约 0.65 美元，18 格上限约 12 美元；整理后上下文变短，实际应更低。跑前等 Boss 点头。
