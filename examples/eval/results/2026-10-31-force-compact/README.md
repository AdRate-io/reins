## 读法

1. **官方线路上请求一次就够。** 三个现场、两遍都是请求后第一步就整理；对比中转站 + system 身份 0/4（踩坑 42），差别在线路不在措辞。
2. **第一轮那一题错（段 C 合计答成旧值 188.76）是单次作答失误。** 补测 6 份摘要都写着正确合计，同一现场第二遍与补测全对。
3. **机械裁剪对照分辨不出差别，是题的局限。** 回落线 60% 只裁掉 seq 2～215，三个预埋事实都在更晚处、没被裁到。整理的价值在于把 2～570 折成一万字的模型自写摘要（目标、决定、下一步都在），而不是这三题。要比"折叠后决定召回"得另出早期事实的题。
4. 机械裁剪对照用"问答时把窗口声明成 340k"制造越线，裁剪量比真实 400k 窗口到 85% 时略多，只作近似。
